# 🎵 音符中的數學 - 課程研發與教學平台

本專案為高中（高二、高三跨領域選修／加深加廣／彈性學習）「音符中的數學」課程網站。
採純靜態前端架構（Vanilla HTML/CSS/JS + KaTeX），專為電腦教室**雙視窗工作流（左側 50% 課程網站，右側 50% Desmos 官方頁面）**優化，並採用**「日系和紙・靜謐素雅（Zen Paper & Ink）」**護眼配色。

---

## 🌟 核心特色與教學工作流

1. **Desmos 專屬超連結直達（舊有連結直連＋新範本空位佔位）**：
   * 現有合適的 Desmos 圖表（共 15 個單元）直接附上官方跳轉超連結，點擊一鍵直達實驗室。
   * 尚未製作的單元（共 12 個單元）自動以「⏳ Desmos 範本製作中（待加入）」空位標記，並提供直達 Desmos 空白繪圖機的備用連結，方便後續隨做隨補。
2. **日系和紙・靜謐素雅風格（Zen Paper & Ink）**：
   * 採和紙米白底（`#faf8f5`）、深炭墨灰字（`#2b2723`）、鼠尾草綠（`#456854`）與焙茶琥珀（`#c06933`），長時間閱讀推導公式舒適不刺眼，並支援右上角切換至「深夜素墨」低光模式。
3. **全課程七大章節（Studio / Workshop 零作業模式）**：
   * 一、單音與發聲
   * 二、音程與律學
   * 三、樂譜與旋律
   * 四、節奏與動態
   * 五、音色與物理
   * 六、和弦與多聲部
   * 七、視覺音遊與演算法
4. **簡潔清晰的課堂結構**：
   * 觀念說明（物理與數學直覺自然連貫） $\to$ 課堂動手操作（勾選任務與算式代碼） $\to$ 隨堂練習（形成性評量與學習歷程導出）。

## ✍️ 如何新增或修改每一堂課的內容？

網站採用**「資料與介面分離（Data-driven）」**設計。
**你完全不需要修改 HTML 或 CSS**，只要打開 [`js/config.js`](file:///Users/laiyicheng/Documents/%E8%81%B2%E9%9F%B3%E6%95%B8%E5%AD%B8/js/config.js)，找到或新增對應的單元代碼即可！

每個單元結構簡潔清晰，範例如下：

```javascript
"1-1": {
  id: "1-1",
  moduleId: "module-1",
  moduleName: "一、單音與發聲",
  title: "聲音的兩大旋鈕與 Desmos 點選發聲",
  status: "ready",
  desmosUrl: "https://www.desmos.com/calculator/...", // 專屬 Desmos 檔案連結
  
  // 觀念說明（支援 Markdown 與 KaTeX 數學式）
  motivation: `聲音在生活與物理中大家早就熟悉...`,
  mathModel: `**核心概念複習與 Desmos 發聲語法**：...`,
  
  // 課堂動手操作清單
  tasks: [
    "輸入 \\operatorname{tone}(a, b)，建立滑桿...",
    "手動拉動頻率滑桿，精準停在 440Hz（標準調音 A 音）。"
  ],
  
  // Desmos 算式代碼（轉為收合式備忘，供課堂參照）
  formula: `a = 440\nb = 0.5\n\\operatorname{tone}(a, b)`,
  
  // 課堂叮嚀
  tips: "現場聽不到聲音 90% 是因為雙開關沒開..."
}
```

### 想要新增一堂全新的課？
1. 在 `COURSE_CONFIG.modules` 裡的目標章節加上你的新單元 ID（例如 `"1-3"`）。
2. 在 `COURSE_CONFIG.units` 物件中新增 `"1-3": { ... }` 並填入標題與內容。
3. 存檔後重新整理網頁，側邊欄目錄與單元內容就會自動生成！
