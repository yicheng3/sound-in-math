# 音符中的數學

高中跨領域選修與彈性學習「音符中的數學」課程教學網站。採純靜態前端架構（Vanilla HTML / CSS / JavaScript + KaTeX），搭配 Desmos 繪圖計算機進行課堂實作。

線上網站：[https://yicheng3.github.io/sound-in-math/](https://yicheng3.github.io/sound-in-math/)

---

## 課程架構

全課程共六大章節、24 個單元（目前 19 個單元已配置專屬 Desmos 檔案，其餘 5 個單元保留備用空白實驗室連結），側邊欄頂部另設「Desmos 範本總覽」與「Desmos 常用操作」參考頁：

1. **一、單音與發聲**（2 單元）：聲音三要素與 Desmos 基礎發聲、用列表播放旋律與和弦
2. **二、音程與律學**（6 單元）：和諧的音、畢達哥拉斯五度相生律、畢氏音差、補充 1（樂理基礎入門）、補充 2（純律）、十二平均律與發聲函數
3. **三、樂譜與旋律**（3 單元）：把簡譜寫成音名列表、補充 3（用下標寫出升降半音與跨八度）、全曲移調與升降 Key
4. **四、節奏與動態**（4 單元）：動態音量與三角函數斷音、高斯符號與鋸齒波斷音、音量控制與指數衰減、8-bit 電玩音效與動態鼓組實驗室（選學）
5. **五、視覺音遊與演算法**（6 單元）：巴哈《螃蟹卡農》幾何對稱變換、Desmos 聽取圖像（`Alt + T`）、薛帕德無限音階、補充 4（循環低音與分段接力）、對數琴鍵與下落式音遊【期末專題】、演算法自動作曲（選學）
6. **音色與物理（選修附錄）**（3 單元）：物理駐波與管樂器邊界條件、自然泛音列與樂器音色合成、傅立葉合成三大經典波形

## 介面與特色

- **版面與字體**：採和紙素雅配色（Zen Paper & Ink），支援右上角切換深色模式，內文使用 Google Fonts 芫荽體（`Iansui`），放大桌面字級以利教室大螢幕投影。
- **資料與介面分離**：所有單元文字、公式、任務清單、隨堂學習單與 Desmos 連結集中於 `js/config.js`，調整內容無需改動 HTML 或 CSS。
- **數學與視覺輔助**：整合 KaTeX 渲染數學式，並於關鍵單元內建靜態波形圖解與 Desmos 範本直達連結。

## 本機預覽

在專案根目錄執行：

```bash
python3 -m http.server 8000
```

接著在瀏覽器開啟 `http://localhost:8000`，或直接用瀏覽器開啟 `index.html`。

## 維護與新增單元

所有單元資料位於 `js/config.js` 的 `COURSE_CONFIG`：

1. **修改既有單元**：在 `COURSE_CONFIG.units` 中找到對應單元 ID（例如 `"1-1"`、`"2-1"`），編輯 `title`、`desmosUrl`、`motivation`、`mathModel`、`tasks`、`formula` 或 `tips` 欄位。
2. **新增單元**：於 `COURSE_CONFIG.modules` 對應章節的 `units` 陣列加入新 ID，並在 `COURSE_CONFIG.units` 補上該單元的物件內容，重新整理頁面即可生效。
